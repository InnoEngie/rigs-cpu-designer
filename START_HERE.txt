RIGS FULL COMPONENT PROTOTYPE — GITHUB UPDATE
================================================

This folder is ready to replace the files in your existing GitHub repository.

QUICKEST UPDATE

1. Open your existing rigs-cpu-designer repository on GitHub.
2. Upload the contents of this folder, preserving the folder tree.
3. Make sure this exact workflow file exists:
      .github/workflows/deploy-pages.yml
4. Commit the upload to the main branch.
5. Open the Actions tab and wait for “Deploy RIGS prototype to GitHub Pages”
   to turn green.
6. Your existing GitHub Pages address will update automatically.

IMPORTANT

GitHub's drag-and-drop uploader can flatten or skip folders. If that happens,
create the folders manually in GitHub, as you did for the first version.

The new prototype stores saved components in the tester's browser. Each tester
has their own local library, and clearing browser site data will clear it.

See GITHUB_PAGES_SETUP.md for the full file-tree and troubleshooting guide.
